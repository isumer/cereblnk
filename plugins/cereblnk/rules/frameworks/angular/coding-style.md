# Angular Coding Style

Extends [`languages/typescript/coding-style.md`](../../languages/typescript/coding-style.md).
Judgment lives in `skills/frameworks/angular/`.

## Files and structure

- File names state the kind: component, service, directive, pipe
- Features are folders; a feature owns its components and services
- Artefacts are generated by the CLI, so structure stays uniform

```text
features/orders/order-list.component.ts
features/orders/order-list.component.html
features/orders/order-list.component.spec.ts
features/orders/order.service.ts
```

Avoid: a file grouping by kind across features. A component declared
in a module that does not own it. A hand-written skeleton that differs
from the generated one.

## Components

- A component renders and delegates; rules live in a service
- Inputs are typed, and outputs emit domain events, not DOM events
- Change detection strategy is stated, not inherited by accident

```typescript
@Component({
  selector: 'app-order-list',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class OrderListComponent {
  @Input({ required: true }) orders!: readonly Order[]
  @Output() settleRequested = new EventEmitter<OrderId>()
}
```

Avoid: business logic inside a template. A component reaching into
another component's state. A subscription created in a constructor.

## Injection

- Dependencies are declared, and their scope is deliberate
- A service that holds state states who owns it and for how long

```typescript
@Injectable({ providedIn: 'root' })
export class OrderService {
  private readonly http = inject(HttpClient)
}
```

Avoid: a service provided in two places with different lifetimes. A
singleton holding per-user state. An injector consulted at runtime to
avoid a declaration.
